### Запуск прокекта

0) - Зайти в свой репозиторий на github.com и скопировать его url
   - Зайти в рабочую папку на своем компьютере и ввести слудующую команду
   - `git clone <url-адрес репозитория>.git`  - скопируем репозиторий на свой компьютер
1) `python -m venv venv` - создать папку окружения
2) - `.\venv\Scripts\Activate.ps1` - активировать окружение в PowerShell
   - `source venv/Scripts/activate` - активировать окружение в Bash

3) `pip install -r requirements.txt`  - установка библиотек пакетным менеджером pip
4) - `uvicorn main:app --reload`    - для запуска сервера на FastApi
   - `python main.py`               - для запуска скрипта

Проект запустится по url адресу
`127.0.0.1:8000` или `localhost:8000`


### Сохранение GIT
1) `git add .`
2) `git commit -m 'Первый коммит'`
3) `git log --oneline`
4) `git config --global user.email 'your@mail.ru'` (вводить только если не авторизованы локально в git)
5) `git config --global user.name 'Your Name'` (вводить только если не авторизованы локально в git)
6) `git push https:// <token> @ <url> .git  master`

### Работа с удаленными репозиториями

|                                                                          |                                                                                                                                                             |
| ------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Отрпавить коммиты (сейвы) на удаленны репозиторий<br>Пример команды выше | `git push -u <имя-удаленного-репозитория> <название-ветки-удаленного-репозитория>`<br>`git push -u origin main`                                             |
